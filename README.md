# Machine Learning Case Studies

Three independent beginner-friendly machine learning projects:

1. [Obesity Level Prediction](01_Obesity_Level_Prediction/)
2. [Amazon Product Analysis](02_Amazon_Product_Analysis/)
3. [Google Play App Review Sentiment Analysis](03_Google_Play_Sentiment_Analysis/)

Each project contains its own `main.py`, `README.md`, `requirements.txt`, `data/` and `results/` folders.

## Quick start
Open the required project folder, install its dependencies and run `python main.py`. Download the relevant dataset from the source link in that project's README and place the CSV in its `data/` folder.

Datasets and generated model binaries are not included in this repository. Check each dataset's source terms before redistribution.
